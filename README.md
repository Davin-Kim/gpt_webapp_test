# 문서온 · 브라우저 문서 작업실

HWPX와 Word(DOCX)를 별도 뷰어 설치 없이 읽고, 기본 문서 내용을 편집한 뒤 새 사본으로 저장하는 웹앱입니다. 기존 행사 홈페이지를 교체했습니다. 예전에 공유한 festival.html 링크는 새 문서온 주소로 연결됩니다.

**사용 주소:** https://davin-kim.github.io/gpt_webapp_test/

## 사용 방법

1. **파일 열기** 또는 문서 파일 끌어놓기로 `.hwpx` / `.docx`를 선택합니다. 기본은 보기 모드입니다.
2. 페이지 썸네일·쪽 번호로 이동하고, 배율·너비/한 쪽 맞춤·두 쪽·모아보기를 선택합니다.
3. **편집**을 누르면 서식 도구와 연속 본문 편집기가 표시됩니다.
4. **내려받기**에서 HWPX / DOCX / HTML / TXT를 선택합니다. 원본 파일은 변경하지 않습니다.
5. **인쇄 / PDF 저장**은 브라우저 인쇄 대화상자를 사용합니다.

처음 보이는 문서는 앱 기능을 설명하는 예시이며 실제 사용자 문서가 아닙니다.

## 지원 기능

- **보기:** 서식 도구 숨김, 한 쪽·두 쪽·여러 쪽, 쪽 이동·썸네일, 확대/축소(25~200%, 자동 맞춤은 15~250% 범위), 너비/한 쪽 맞춤, 전체 화면, 검색, 인쇄.
- **편집:** 제목/본문, 글꼴·크기·색, 굵게·기울임·밑줄·취소선, 위/아래 첨자, 형광펜, 서식 지우기, 정렬, 글머리/번호 목록, 들여/내어쓰기, 줄 간격, 문단 앞뒤·첫 줄 간격.
- **개체:** 표 삽입, 행/열 추가·삭제, 셀 병합·분할, 제목 행, 열 너비 조절, 이미지 삽입·크기 조절, 링크, 수동 쪽 나누기.
- **용지:** A4/A3/A5/Letter, 세로/가로, 상하좌우 여백.
- **작업:** 실행 취소·다시 실행, 찾기·한 개/전체 바꾸기, 문서명, 글자·단어 수, 브라우저 임시 저장·복구.
- **변환:** HWPX→DOCX / DOCX→HWPX, 각 형식으로 다시 저장. 내보내기 전 변환 사본임을 안내합니다.

글꼴 선택은 기기에 설치된 글꼴을 사용합니다. 없는 글꼴은 브라우저에서 대체됩니다. 셀 병합은 드래그로 인접 셀을 선택한 후 사용하며, 이미지 크기 조절은 편집 모드에서 선택한 이미지의 모서리로 수행합니다.

## 호환성의 정확한 범위

한글·Word의 자체 엔진을 실행하는 제품이 아닙니다. 본문 중심의 변환형 편집기이며 두 제품과 100% 동일한 조판이나 무손실 왕복을 보장하지 않습니다.

- HWPX의 본문·기본 글자 모양·표(기본 셀 병합 포함)·임베디드 이미지를 불러옵니다. Word는 의미 기반 HTML에 직접 지정된 글꼴·크기·색·정렬·간격을 보완합니다. 복잡한 스타일 상속이나 임의 글꼴은 일부 기본값으로 바뀔 수 있습니다.
- 머리말/꼬리말/각주, 다단/복수 구역, 도형·차트·수식·OLE·글맵시·텍스트 상자, 자동 필드·변경 추적은 원본대로 보존하지 못합니다. 일부는 본문에 펼쳐지고 일부는 제외됩니다. 가져오기 후 변환 안내에서 확인할 수 있습니다.
- 페이지는 브라우저의 글꼴과 첫 구역 용지 크기를 기준으로 재배치합니다. 원본 페이지 수·줄바꿈·부동 위치와 달라질 수 있습니다. 수동 쪽 나누기는 별도로 보존합니다. 편집 중에는 연속 본문이며 보기 모드에서 다시 쪽을 나눕니다.
- 긴 문단·목록·일반 표는 나누어 표시합니다. 나눌 수 없는 큰 이미지/병합 표/한 행은 한 쪽에 맞춰 축소하며 안내합니다. 세로 병합을 포함하는 복잡한 표의 DOCX 변환 결과는 원본 앱 확인을 권장합니다.
- 새 파일은 기본 본문·지원되는 서식·표·이미지 기반으로 재생성합니다. 지원하지 않는 원본 개체는 다시 생성되지 않습니다. 중요한 문서는 원본을 보관하고 저장한 사본을 한글·Word에서 확인하세요.
- 구형 바이너리 `.hwp` / `.doc`, 암호화·배포용·손상 문서는 지원하지 않습니다. HWPX/DOCX로 변환한 파일을 사용하세요. 문서 최대 25MB, 압축 해제 크기 80MB, ZIP 항목 4,096개, 표시 1,000쪽 제한입니다. 이미지 삽입은 PNG/JPEG/GIF/WebP 5MB까지입니다.

## 저장과 개인정보

서버 저장·외부 업로드·기기 간 동기화는 없습니다. 파일 선택 후 브라우저에서만 파싱·표시·변환합니다. 외부 이미지 참조는 제거하고, 임베디드 이미지만 사용합니다. 파일 내부 HTML·스크립트·위험한 스타일은 정리하며 ZIP 크기를 검사합니다.

작업 1개를 이 브라우저 IndexedDB(`munseoon-documents`, drafts/current)에 약 750ms 뒤 자동 저장합니다. 재접속 시 **이어서 열기**로 복구합니다. 저장 실패는 성공으로 표시하지 않고 재시도를 제공합니다. 저장소 초기화·시크릿 모드·기기 변경에 대비해 파일도 내려받으세요. 여러 탭 동시 편집은 피하세요. 새 문서/파일을 열면 현재 작업 임시 저장이 교체됩니다.

구버전 MY MONEY / 점심 앱 / 행사 홈페이지의 브라우저 저장 데이터는 읽거나 삭제하지 않습니다. 실제 사용자 문서나 개인 엑셀은 Git·배포 파일에 포함하지 않습니다. HWPX/DOCX 등의 파일은 .gitignore 및 개발 서버 제공 차단 목록에 추가했습니다.

## 실행

Node.js 22 이상, 검증 환경 Node.js 24 / Chromium.

```sh
npm ci
npm run dev
```

개발 경로는 `/gpt_webapp_test/`이고, 기본 포트는 5173입니다.

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

브라우저 테스트는 기본 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`로 변경합니다. CI에서는 Playwright Chromium을 설치하고 해당 경로를 전달합니다. main에 반영되면 테스트·브라우저 시나리오·빌드 후 dist만 GitHub Pages로 배포합니다.

## 실제 검증

단위 테스트 2개와 브라우저 시나리오 8개를 실행했습니다.

- 보기 모드 도구 숨김, 배율, 쪽 이동, 두 쪽/모아보기, 검색, 모바일 화면
- 생성한 실제 ZIP/XML 형식 HWPX와 DOCX 파일의 본문·표·이미지 가져오기
- 가져온 본문 수정 → HWPX 저장 → 재열기 → DOCX 저장 → 재열기, 텍스트와 표 보존
- DOCX 파일의 HWPX 변환, 이미지 크기 복원, 수동 쪽 나누기 저장·재열기
- HWPX 네이티브 XML의 pageBreak 속성 및 mimetype 첫 항목 무압축 저장 검사
- Word의 직접 지정된 글꼴·18pt·색·가운데 정렬 저장 후 재가져오기
- 새 문서, 글자 서식·위 첨자, 표·행 추가, 검색/전체 바꾸기, 실행취소
- 임시 저장 후 재접속 복구, 저장 실패 안내, 손상 파일 시 기존 문서 유지
- 긴 문단 900회 반복을 여러 쪽으로 분할한 뒤 텍스트가 모두 남는지 검사
- 가로 용지, 악성 HTML/외부 이미지 제거, 텍스트 내려받기

테스트 파일은 인위적으로 생성한 기능 검증용 문서입니다. 사용자의 실제 HWPX/DOCX 파일은 아직 제공되지 않았으며, 외부 한컴오피스·Microsoft Word 설치본에서의 직접 렌더링 검증은 수행하지 않았습니다. 브라우저 인쇄 대화상자·OS PDF 저장·프린터 결과는 사용 환경에 따라 달라집니다.
