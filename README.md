# 제16회 안산읍성문화예술제 — 행사 홈페이지 디자인 시연

제공된 행사 포스터와 사용자가 복사해 제공한 주간한국 기사 본문을 바탕으로 만든 반응형 행사 소개 사이트입니다. 실제 공식 사이트나 예약 서비스가 아닙니다.

## 실행

Node.js 22 이상 권장 (검증: Node.js 24).

```sh
npm ci
npm run dev
npm test
npm run test:e2e
npm run build
```

개발 경로: `/gpt_webapp_test/`. 빌드 파일: `dist/`. 브라우저 테스트는 시스템 Chromium(`/usr/bin/chromium`, `CHROMIUM_PATH`로 변경)을 사용합니다.

## 구성

- 포스터의 연분홍·주홍·청색, 관모·갓·전통 문양을 재해석한 자체 SVG 메인 비주얼
- 축제 소개, 프로그램, 출연진, 오시는 길, 관람 안내
- 유형별 프로그램 필터, 상세 모달, 관심 프로그램 저장·삭제 및 새로고침 유지
- 한국 시간 기준 행사 캘린더(.ics) 다운로드
- 외부 지도와 기사 원문 링크, FAQ, 모바일 메뉴, 키보드·줄인 동작 설정 지원

관심 일정은 `ansan-festival.saved` 키로 이 브라우저 localStorage에 저장하며 실제 참가 예약이 아닙니다. 저장 실패 시 오류를 알리고 성공으로 표시하지 않습니다. 이전 가계부나 메뉴 앱의 브라우저 저장 데이터는 읽거나 삭제하지 않습니다.

## 근거와 시연용 보완

기사 URL: https://weekly.hankooki.com/news/articleViewAmp.html?idxno=7189067

기사 사이트 직접 접근은 실행 환경에서 차단되었으나 사용자가 전체 본문을 제공해 해당 내용을 반영했습니다. 기사 본문과 포스터는 콘텐츠 근거로만 사용했습니다.

확인된 정보: 2026년 10월 17일 11~17시, 안산읍성 일원, 정조대왕 능행차 공동재현, 제16회 안산읍성문화예술제, 주최 안산시·주관 안산문화원, 경기도 기념물 제127호 안산읍성 및 관아지, 수암마을 체험·그리기, 전시관 앞 버스킹, 천년안산 음악회 및 포스터 출연진. 세부 시간표는 포스터 기준입니다.

시연용 보완: 홍보 카피, 일부 상세 프로그램 설명, 행사장 내 미확정 위치의 포괄적 표현, 관람 안내 FAQ, 실제 축척·도로와 관계없는 능행차 개념도, 자체 제작 그래픽. 무료 입장·예약 방식·교통·주차·우천 방침은 확정 사실로 주장하지 않습니다. 사진을 구할 수 없는 출연진은 가상 인물 사진 대신 타이포그래픽으로 표현했습니다. 상단과 하단에 시연 사이트임을 표시하고 관련 항목에도 근거를 안내합니다.

## 검증 및 배포

단위 테스트: 포스터 기반 프로그램과 분류 필터, 한국 시간→UTC 캘린더 값.
브라우저 테스트: 섹션 이동·필터·상세 모달·관심 일정·재접속 유지·삭제·캘린더 다운로드·FAQ·모바일 메뉴·가로 넘침·저장 실패.

기존 GitHub Pages 배포를 유지합니다. main에 반영되면 GitHub Actions가 테스트·빌드 후 dist만 배포합니다.
주소: https://davin-kim.github.io/gpt_webapp_test/

파일: `src/model.js` 행사 데이터·캘린더 / `src/art.js` 자체 SVG / `src/app.js` 화면·상호작용 / `src/style.css` 반응형 스타일. 개인 엑셀·실제 가계부 데이터는 소스·빌드에 포함하지 않습니다.

## HTML 파일 하나로 사용

`festival.html`은 CSS·JavaScript·SVG를 모두 포함한 단일 HTML입니다. 다운로드 후 더블클릭해 열거나 파일 전체를 복사해 사용할 수 있습니다. 별도 설치·서버 없이 동작하며, 인터넷이 없어도 화면과 프로그램 기능이 동작합니다. 외부 지도·기사 링크는 인터넷이 필요합니다. 단일 파일은 외부 웹폰트 대신 기기에 설치된 글꼴을 사용합니다. file:// 환경의 브라우저 저장 정책에 따라 관심 일정 저장이 제한되면 화면에 안내합니다.

`npm run build`가 앱을 빌드한 뒤 `scripts/build-single.mjs`로 원본 앱에서 이 파일을 자동 생성합니다. 별도로 손으로 수정하지 말고 src를 수정한 뒤 다시 빌드하세요. 배포 결과의 `festival.html`도 동일한 파일입니다.

단일 파일 접속: https://davin-kim.github.io/gpt_webapp_test/festival.html
