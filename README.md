# 문서온 · 텍스트 보기·편집 전용

사용 환경의 보안 조건을 고려해 파일·드라이브·저장소 기능을 제거한 버전입니다.

주소: https://davin-kim.github.io/gpt_webapp_test/

## 남아 있는 기능

- 텍스트 직접 붙여넣기, 페이지 형태로 보기
- 보기 / 편집 모드 전환, 확대·축소, 두 쪽·여러 쪽, 쪽 이동
- 글자·문단 서식, 표, 목록, 쪽 나누기, 용지 설정
- 검색·바꾸기, 실행 취소, 직접 선택·복사

**작업은 현재 탭의 메모리에만 유지됩니다. 새로고침하거나 탭을 닫으면 사라집니다. 필요한 내용은 직접 복사하세요.** ‘내용 복사’는 텍스트를 선택하는 화면을 열 뿐 클립보드 API나 자동 복사 권한을 사용하지 않습니다.

## 제거한 기능

파일 선택/열기, 드래그앤드롭 가져오기, 업로드, 다운로드, 이미지 첨부, HWPX/DOCX 파싱·변환, 파일 시스템 접근, IndexedDB/localStorage/sessionStorage 임시 저장·복구, 드라이브 연동, 인쇄/PDF 버튼을 제거했습니다. 관련 변환·파일 라이브러리도 의존성과 배포 파일에서 제외했습니다. 기존 문서 파일 자체를 직접 열 수는 없습니다.

서버 전송, 외부 API 호출, 분석 스크립트, 클라우드 저장을 사용하지 않습니다. CSP에서 네트워크 연결·이미지·프레임·플러그인·웹 워커·폼 전송을 제한하며 외부 웹폰트도 사용하지 않습니다. 필요한 정적 앱 코드와 스타일은 동일한 GitHub Pages 주소에서 받습니다.

기관에서 GitHub Pages 주소 자체를 차단하는 경우 앱 기능 제거만으로 접속을 보장할 수 없습니다. 보안 정책을 우회하는 구성이 아니며 해당 기관에서 허용된 환경에서 사용해야 합니다. 이전 브라우저 저장 데이터는 읽거나 변경하지 않습니다.

## 실행과 검증

```sh
npm ci
npm run dev
npm test
npm run test:e2e
npm run build
```

Node.js 24 / Chromium으로 검증했습니다. 기본 개발 경로는 `/gpt_webapp_test/`입니다. 시스템 Chromium은 `/usr/bin/chromium` 또는 `CHROMIUM_PATH`를 사용합니다.

브라우저 테스트는 파일 선택 API·FileReader·IndexedDB·localStorage·sessionStorage·fetch 접근을 차단한 상태에서 실행합니다. 텍스트 붙여넣기·서식·표·검색 바꾸기·페이지 보기·배율·복사용 텍스트 선택·새로고침 초기화·모바일 화면을 확인합니다. 파일 선택·업로드·다운로드 UI가 없는지도 검사합니다.

main에 반영되면 테스트·빌드 후 dist만 GitHub Pages에 배포합니다. 기존 festival.html 주소는 새 홈페이지로 연결됩니다. 오픈소스 라이선스는 빌드 시 THIRD-PARTY-NOTICES.txt에 포함합니다.
