# 제16회 안산읍성문화예술제

제공 포스터와 사용자가 제공한 기사 본문을 바탕으로 만든 반응형 행사 소개 사이트입니다. 실제 공식 홈페이지가 아닌 디자인 시연입니다.

## 실행

Node.js 24에서 `npm ci` 후 `npm run dev`로 시작합니다. `npm test`, `npm run test:e2e`, `npm run build`로 검증합니다. 브라우저 테스트는 기본적으로 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`로 변경할 수 있습니다.

## 구성

- 포스터의 연분홍·청색·주홍색과 전통 문양을 재구성한 자체 SVG 메인 그래픽
- 행사 개요, 프로그램 8개 필터와 상세 보기, 전체 시간표
- 현재 탭에서만 유지하는 관심 일정 추가·삭제
- 출연진 6명, 능행차 구간 개념도, 지도 검색 링크, 관람 안내
- 모바일 메뉴, 키보드 탐색, 네이티브 상세 대화상자

날짜·시간·출연진은 제공 포스터 기준입니다. 소개 문구는 웹 안내용으로 작성했습니다. 주차·관람료·예약·우천 운영 등 자료에 없는 사항은 미확인으로 안내합니다. 지도는 실제 축척이 아닌 개념도이며 인물 사진 대신 글자 그래픽을 사용합니다.

## 보안과 저장

파일 업로드·다운로드, 드라이브, 브라우저 영구 저장, 외부 API·폰트 요청을 사용하지 않습니다. 관심 일정은 새로고침하면 초기화됩니다. 원본 문서와 개인 거래 데이터는 소스 및 배포물에 포함하지 않습니다. 외부 지도와 기사 링크는 사용자가 직접 누를 때 이동합니다.

## 배포

Vite base는 `/gpt_webapp_test/`입니다. main에 푸시하면 GitHub Actions가 단위·브라우저 테스트와 빌드 후 GitHub Pages에 자동 배포합니다.

https://davin-kim.github.io/gpt_webapp_test/

기존 `/festival.html` 주소도 메인 페이지로 연결합니다.

## 검증

포스터 날짜·프로그램 구성과 분류 필터 2개 단위 테스트, 상세 보기·시간표·관심 일정 추가/삭제·새로고침 초기화·모바일 메뉴·FAQ·가로 넘침을 확인하는 3개 Chromium 테스트를 제공합니다. 브라우저 테스트는 저장소·파일·fetch API를 차단한 상태에서 실행합니다.
