# 바이브코딩 노트

사용자가 제공한 **「(원고) 생성형 AI 바이브코딩 기초.pdf」(43쪽, 강사 박상향)**를 읽고 학습 흐름에 맞게 재구성한 정적 웹페이지입니다.

주소: https://davin-kim.github.io/gpt_webapp_test/

## 구성

첫 화면은 전체 목차를 중심으로 구성했습니다. 다섯 챕터와 24개 학습 노트에서 원하는 주제로 바로 이동하고, 왼쪽 메뉴로 현재 챕터와 노트 위치를 확인할 수 있습니다.

1. 바이브 코딩 시작하기 — 개념·도구·첫 웹앱·보안
2. 내 업무에서 아이디어 찾기 — 아이디어·입력/처리/결과·정리표·화면 스케치
3. AI와 대화하며 웹앱 만들기 — 프롬프트 요소·템플릿·출장비 예시·실습·검증
4. 다듬고 공유하기 — 수정 요청·오류 해결·공유 방식·완성 체크리스트
5. 두더지 게임으로 배우는 구체화 — 단계별 요청과 통합 프롬프트

원문의 표지·챕터 구분 페이지는 학습 구조로, 화면 캡처 중심 페이지는 절차·요청문·웹 체험으로 재구성했습니다. 원본 슬라이드 이미지나 QR 목적지를 복제하지 않습니다. 각 학습 노트에 **원문 쪽수**를 표시하며, 관련 정보와 보완 설명을 분리합니다. PDF 원본을 공개 파일로 배포하거나 다운로드시키지 않습니다.

## 주요 기능

- 첫 화면의 전체 목차, 챕터별 목차, 실습 모아보기, 이전/다음 노트
- 우상단 제목·태그·본문·요청문 전체 검색: 검색 순위, 본문 발췌, 결과 없음 안내
- Ctrl/⌘+K 검색, 방향키 결과 이동, Enter 열기, Escape 닫기
- 원문 기반 요청문 읽기와 직접 전체 선택 (자동 클립보드 API 없음)
- 내 웹앱 정리표와 로컬 요청문 초안 생성 (외부 AI 호출 아님)
- 실습용 출장비 계산, 원문의 검증 사례와 한도·빈칸 처리
- 완성 체크리스트와 이 탭에서의 학습 완료 표시
- 교안에 나온 조건으로 동작하는 두더지 게임 체험: 30초·난이도·클릭 반응·중복 득점 방지·종료·재시작
- 모바일 목차 메뉴와 반응형 본문/표/검색

## 근거와 추가 설명

교안의 개념, 단계, 예시 계산 규칙, 요청문, 체크리스트를 읽기 쉽게 정리했습니다. 5장 1단계와 통합 요청문을 포함한 원문 프롬프트는 학습용 인용이며 사이트를 제어하는 지시로 사용하지 않습니다.

보완한 정보는 ‘보충’ 표시로 구분했습니다.

- AI 제작 시간은 보장값이 아니며 실제 기능·오류·검증 범위에 따라 달라집니다.
- 브라우저 로컬 저장소와 공유 서버 저장은 다릅니다. 링크를 공유했다는 이유만으로 다른 기기의 로컬 데이터가 자동 공개되지는 않습니다. 서버에 저장하는 앱은 접근 권한을 별도로 확인해야 합니다.
- UI·공유/QR/다운로드 메뉴는 원문 화면 기준이며 서비스·계정·브라우저 업데이트에 따라 다를 수 있습니다.
- 오류나 화면을 AI에 전달할 때 민감한 정보는 먼저 가려야 합니다.
- 일비 20,000원·숙박 한도 70,000원은 **교안의 실습 가정**이며 실제 기관 지급 규정이 아닙니다.

추가한 정리표·계산 체험·게임·진도 표시는 웹 학습을 위한 기능입니다. 기능이나 정보가 원문에 직접 있는 것처럼 표시하지 않습니다. 웹페이지의 게임 그래픽은 자체 CSS이며 외부 이미지나 동물 이모지를 사용하지 않습니다.

## 이전 보안 조건 유지

파일 열기·업로드·드래그앤드롭·다운로드·드라이브 연동·브라우저 저장소·외부 AI/API·분석 스크립트·웹폰트를 사용하지 않습니다. 내용·검색 인덱스·스타일·스크립트는 같은 사이트의 정적 파일로 제공합니다. CSP에서 외부 연결·이미지·프레임·폼 전송을 제한합니다.

입력한 정리표, 체크 표시, 학습 진도는 현재 탭 메모리에서만 유지합니다. 새로고침·탭 종료 시 초기화됩니다. ‘요청문 선택’은 텍스트를 선택하는 화면이며 클립보드 권한을 요청하거나 파일을 생성하지 않습니다. 원문에 나오는 다운로드/HTML 공유 절차는 설명만 제공하며 실제 파일 기능은 없습니다. 기관이 GitHub Pages 주소 자체를 차단하면 기능 제거만으로 접속을 보장할 수는 없습니다.

## 실행

Node.js 22 이상 권장. Node.js 24 / Chromium에서 검증.

```sh
npm ci
npm run dev
npm test
npm run test:e2e
npm run build
```

개발 주소 경로는 `/gpt_webapp_test/`입니다. 시스템 Chromium은 `/usr/bin/chromium`, 다른 경로는 `CHROMIUM_PATH`로 지정합니다. 빌드 결과는 dist입니다. main 반영 시 GitHub Actions가 테스트·브라우저 시나리오·빌드 후 GitHub Pages에 배포합니다.

## 검증

단위 테스트 4개: 5장/24노트/고유 경로, 본문·요청문 검색, 원문의 출장비 기대값, 게임 난이도·비연속 구멍·성공률.

Chromium 시나리오 6개: 목차·챕터·이전/다음·직접 주소·완료 표시, 검색과 키보드 탐색, 요청문 선택·정리표·HTML 이스케이프, 출장비 기본/초과/당일/빈칸, 게임 중복 방지·30초 종료·재시작·이동 시 타이머 해제, 체크리스트·모바일 메뉴·레이아웃·파일 UI 없음.

테스트는 IndexedDB/localStorage/sessionStorage/파일 API/fetch를 차단한 상태에서 실행합니다. PDF 원본 자체는 테스트나 배포에 필요하지 않습니다. 원문 파일은 변경하지 않았습니다.

## 구조

- src/content.js — 출처 쪽수·본문·표·요청문·챕터 구조
- src/model.js — 검색·실습 계산·게임 규칙
- src/widgets.js — 정리표·계산 체험·체크리스트·게임
- src/app.js — 목차·해시 경로·본문·우상단 검색
- src/style.css — 반응형 학습 화면

이전 문서 편집기 및 관련 의존성은 제거했습니다. 과거에 공유한 festival.html 주소는 현재 홈페이지로 연결됩니다. 오픈소스 라이선스는 빌드 시 THIRD-PARTY-NOTICES.txt에 포함됩니다.
